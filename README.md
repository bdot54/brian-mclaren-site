# Brian D. McLaren

The modernized website for author, speaker, activist, and public theologian
Brian D. McLaren.

## What the site includes

- An editorial homepage centered on Brian’s full body of work and current books
- Guided “Start Here” pathways for new readers
- A curated book library with access to the complete archive
- Current speaking availability, sample topics, and a speaking inquiry form
- Events, media, press resources, recent writing, and archive search
- A first-party newsletter signup list
- Accessible responsive navigation and social sharing metadata

Newsletter signups and speaking inquiries use the site’s D1 database. Drizzle
migrations are stored in `drizzle/`.

## Development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
npm run build
npm test
```
